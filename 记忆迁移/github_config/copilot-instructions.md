## 项目概览

室内四旋翼竞赛无人机，基于**匿名凌霄飞控**（STM32F407 + 凌霄IMU闭源模块）。
开发语言：**纯C语言**（不是C++）。IDE：**Keil5**，烧录目标：**STM32F407**。

### 硬件架构
- **STM32F407**：可编程主控，运行本项目代码
- **凌霄IMU**：闭源，通过匿名通信协议与STM32通信（不可烧录）
- **凌霄光流传感器**：通过同一协议上报速度/位置数据
- **凌霄数传**：透传协议数据至地面站

### 飞行模式

| 模式 | 说明 |
|------|------|
| 0 | 姿态自稳 — CH1-CH4直接控制姿态和油门 |
| 1 | 自稳+定高 — CH3控制垂直速度 |
| 2 | 定点 — CH1/CH2控制水平速度，CH3控制垂直速度 |
| 3 | **程控** — 摇杆不参与，完全由代码指令控制 |

### AUX1通道（CH5）模式映射
| AUX1量程 | 对应模式 |
|-----------|----------|
| 1000~1200 | 模式1（自稳+定高） |
| 1200~1400 | **失控保护区间**，不可用 |
| 1400~1600 | 模式2（定点） |
| 1600~1800 | **失控保护区间**，不可用 |
| 1800~2000 | 模式3（程控） |

> 注意：1200-1400和1600-1800属于失控保护间隔区，**不能**将AUX1配置到这两个区间。

### 地址快选表
| 地址 | 设备 |
|------|------|
| `0xFF` | 广播（发CMD/0x41用这个） |
| `0x60` | 凌霄IMU（读写参数用） |
| `0x61` | 本机STM32（来自外部设备的指向类） |
| `0xAF` | 上位机（CK返回用） |

## 用户代码开发规则

### 唯一的用户入口
**所有用户逻辑**必须从 `FcSrc/User_Task.c` 的 `UserTask_OneKeyCmd()` 函数出发，该函数由调度器50Hz调用。不要修改 `ANO_DT_LX.c`、`LX_FC_Fun.c` 等底层文件的逻辑，除非是明确的协议扩展。

### 调度器使用规则
- 时间敏感操作（如传感器读取）：100Hz或200Hz循环
- 控制指令发送：50Hz循环（与`UserTask_OneKeyCmd`同频）
- 状态检查/日志：20Hz或2Hz循环
- **严禁**在循环中使用阻塞延时（`HAL_Delay`、`delay_ms`等）

### 程控模式前置条件
发送任何位置/速度指令前，必须确认 `fc_sta.fc_mode_sta == 3`（程控模式已激活）。

## 凌霄通信协议快速参考

> 完整协议规则见：`.github/instructions/lingxiao-protocol.instructions.md`

**帧格式**：`0xAA | 目标地址 | CMD | 数据长度N | 数据[N字节] | SC | AC`

**双向校验（SC/AC）**：校验覆盖帧头到 DATA 结束，共 LEN+4 个字节：
```c
for (i = 0; i < (data_buf[3] + 4); i++) { SC += data_buf[i]; AC += SC; }
```

**关键帧ID**：
- `0x41` 实时控制帧（程控模式下发送目标姿态/速度）
- `0xE0` CMD命令帧（解锁、模式切换、一键起降等）
- `0xA0` LOG打印功能字符串帧（下位机向上位机发送文本信息）
- `0x03` 姿态角（从 IMU 接收）
- `0x05` **对地高度**（室内竞赛关键！）
- `0x07` 飞行速度（从 IMU 接收）
- `0x06` 飞控状态（从 IMU 接收，含模式和解锁状态）
- `0x08` **XY位移**（室内竞赛关键！光流/UWB数据）
- `0x0E` 外接模块状态（检查光流/GPS是否正常工作）

## C代码规范

> 完整规范见：`.github/instructions/drone-c-conventions.instructions.md`

- **模块结构**：每个功能模块一对`.c/.h`文件，`.h`只暴露必要接口
- **命名**：全局变量下划线前缀（`_变量名`或直接`变量名`），结构体名加`_st`后缀，联合体加`_un`后缀，函数名大驼峰或下划线分隔
- **数据打包**：跨协议的结构体必须加 `__attribute__((__packed__))`
- **状态机**：用 `static u8 step` + `switch-case` 实现，不用递归和动态内存

## STM32F407 / Keil5 规则

> 完整规则见：`.github/instructions/keil5-stm32f407.instructions.md`

- STM32F407：168MHz主频，APB1=42MHz，APB2=84MHz，定时器时钟=APBx×2
- 中断优先级分组：第4组（4位全部用于抢占优先级）
- **不使用C++**，不使用动态内存（`malloc`/`free`）
- Keil编译目标：`ProjectSTM32F407/ANO_LX_STM32F407.uvprojx`

1. 不得修改 `DriversMcu/` 底层MCU驱动（除非有明确需求）
