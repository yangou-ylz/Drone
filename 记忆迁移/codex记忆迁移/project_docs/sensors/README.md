# 匿名系列外部传感器资料库

更新时间：2026-07-19

本目录用于归档本项目后续接入或调试外部传感器时获取到的权威资料，尤其是匿名系列传感器，例如匿名光流、激光高度、UWB、测距模块等。

## 使用规则

1. 优先使用本地 `用户手册/`、`project_docs/`、`memories/` 中已有资料。
2. 本地没有资料时，可以联网查找官方或权威资料。
3. 获取到资料后，应保存到本目录或子目录，并记录来源、日期、适用硬件版本。
4. 若资料改变了协议字段、坐标系、单位、无效值或接线方式，必须同步更新：
   - `CODEX_MEMORY_INDEX.md`
   - 相关 `project_docs/`
   - `memories/repo/dev-log.md`
5. 不允许凭“同系列大概兼容”直接假设字段；必须通过资料、源码或抓包验证。
