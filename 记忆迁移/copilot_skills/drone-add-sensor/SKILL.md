# 添加外部传感器接入代码

## 帧ID选择
| 帧ID | 类型 | 适用传感器 |
|------|------|-----------|
| `0x32` | 通用位置 | UWB定位、视觉里程计、室内定位系统 |
| `0x33` | 通用速度 | 光流（速度模式）、多普勒测速 |
| `0x34` | 通用测距 | 激光测距、超声波、红外测距 |

## 步骤

### 1. 确认传感器信息
- **帧类型**：位置(0x32) / 速度(0x33) / 测距(0x34)
- **通信接口**：UART几号，波特率多少
- **数据来源**：传感器直接输出，还是MCU解析后再上报
- **坐标系**（0x32专用）：安装时机头朝X轴正方向，机体左侧朝Y轴正方向
- **硬件前置状态**：新增/排查外部传感前，先确认 `0x0D` 电压帧正常、`0x0E` 外接状态合理。若电压或外部传感一插串口就消失，优先查 UART2 串口桥反灌/电平，以及 `UART5/USART5` 是否误接 USB-TTL `TX`；不要直接改 0x32/0x33/0x34 打包。
- **USART5边界**：`UART5/USART5` 是 STM32 ↔ 凌霄IMU主通信口，不是外部传感器或树莓派主动发送口。树莓派只读 IMU 数据只能 `飞控USART5 RX → USB-TTL RX` 和 GND 旁路监听。

### 2. 参照协议字段
加载 `.github/instructions/lingxiao-protocol.instructions.md`，确认字段格式：
- **0x32**：POS_X/Y/Z (s32×3, cm，**0x80000000=无效**) — LEN=12
- **0x33**：SPEED_X/Y/Z (s16×3, cm/s，**0x8000=无效**) — LEN=6
- **0x34**：DIRECTION(u8)+ANGLE(u16,度)+DIST(**u32**,cm，**0xFFFFFFFF=无效**) — LEN=7

> ?? **0x34 Bug 提醒**：`LX_FC_EXT_Sensor.h` 中 `distance_cm` 可能声明为 `s32`，需修正为 `u32`，否则无效值 `0xFFFFFFFF` 被读为 `-1`。

### 3. 生成传感器数据解析函数
在 `LX_FC_EXT_Sensor.c` 中参照已有代码，添加从 UART 解析传感器原始数据的逻辑。

### 4. 生成上报函数
参照 [传感器上报模板](./assets/sensor_report_template.c) 生成对应帧的发送代码。

### 5. 注册到调度器
在 `User_Task.c` 的合适调度频率中调用上报函数：
- 一般 50Hz 调用（与主控制循环同频）
- 若传感器有新数据标志，先检查标志再上报

### 6. 验证数据
观察上位机软件是否收到正确帧，检查：
- 校验字节通过（SC/AC 正确）
- 数值单位正确（cm/s，cm）
- 无效值 (0x80000000/0x8000/0xFFFFFFFF) 时飞控不响应
